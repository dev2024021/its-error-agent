서비스: WO (wipson.com)
장애 제목: 특허문헌 다운로드 시 "잘못된 접근" 오류 (200건 초과 시 재현)

고객 문의 원문: 특허문헌 다운로드 시도 시 오류 메세지("잘못된 접근으로 인해 오류가
발생하였습니다. 관리자에게 문의 부탁 드립니다.")가 계속 발생합니다.
- 로그아웃 후 재로그인, 창을 닫았다가 다시 접속해도 동일한 오류가 반복됨
- 로그인상태설정 확인 시 본인만 사용 중(동시 로그인 아님)
- 오늘 다운로드 이력 없음. 다른 날도 비슷하게 사용했는데 오늘만 갑자기 발생
- 마이페이지에서 보유포인트 확인 결과 무제한으로 표시됨(포인트 소진 아님)
- 선택문헌 말고 전체문헌으로 선택해 200건 이상 넘어가면 이 문제가 발생하는 것 같음
- 나눠서 다운받으려 해도 200건 이상 넘어가면 또 다운이 안 됨
- 다운로드가 되지 않아 업무 차질 발생 중, 빠른 확인 요청

재현 화면(wipson.com 다운로드, "텍스트" 모드):
1. 다운로드 범위 선택에서 "전체문헌 911건" 선택(선택문헌 200건, 범위 직접입력도 가능)
   - "1회 최대 다운로드 문헌수는 10,000건(단, 대표문헌 또는 전체청구항 포함 시 1회
     2,000건)"으로 안내됨
2. 항목 선택: 현재 선택된 항목 25/142(기본항목 25, 고급항목 0)
3. "911건이 다운로드 됩니다. 다운로드 하시겠습니까?" 확인창에서 "다운로드 실행" 클릭
4. 아래 알림창 발생:
   "잘못된 접근으로 인해 오류가 발생 하였습니다. 관리자에게 문의 부탁 드립니다.
   error: download total count vs authorization total count and the number is wrong"

참고: 동일한 오류 메시지가 원문(PDF) 다운로드 등 다른 다운로드 화면에서도 보고된 바
있어, 여러 다운로드 기능이 공유하는 건수 검증 로직에서 발생하는 것으로 추정됨.
